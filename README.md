# Dossiê Familiar 360™

MicroSaaS de organização e continuidade familiar.

## Arquitetura

- Frontend: React + TypeScript + Vite
- UI: Tailwind CSS + componentes acessíveis
- Backend: Supabase/PostgreSQL
- Auth: Supabase Auth
- Segurança: Row Level Security (RLS)
- Fonte de verdade: GitHub
- Lovable: somente visualização/prototipagem

## Princípios

1. Não armazenar senhas bancárias, PINs, tokens ou códigos 2FA.
2. Dados de cada família devem ser isolados por RLS.
3. Interface simples, legível e acessível para pessoas idosas.
4. Mobile-first.
5. Nenhuma alteração no repositório `petvida-senior`.

## Módulos

- Dashboard
- Pessoas
- Saúde
- Patrimônio
- Dinheiro
- Casa & Rotina
- Vida Digital
- Emergência
- Revisão periódica
- Configurações
